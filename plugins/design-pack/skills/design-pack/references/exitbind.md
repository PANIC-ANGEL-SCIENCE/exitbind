# Exitbind relationship and integration boundary

This is an independently authored skills-only design pack for possible future distribution alongside Exitbind. It does not contain Exitbind, external design repositories, renderers, hooks, an MCP server or a new runtime. Its core process is usable by reading this pack in any capable assistant.

Exitbind's inspected 0.31.26 plugin manifests use `plugin.json`, `.claude-plugin/plugin.json`, `.codex-plugin/plugin.json` and a `skills/` directory. This package follows that layout as a candidate. The repository's existing checker hardcodes its own plugin; passing this package's checks does not mean that checker or a provider installer accepts this pack.

## In an existing governed task

Keep the original request and agreed design brief in the task's current records. Select only the needed design references, current project profile and acceptance criteria. Record loaded files and their versions. Role perspectives complement the configured lead/worker/reviewer roles; they do not rename, replace or expand their authority.

Bind design findings and verification to the actual artifact and tracked inputs according to installed Exitbind guidance. A styleframe review does not accept the final implementation. A package validator cannot accept a design task. Preserve missing, failed and omitted checks honestly.

## Future project-local capability use

The inspected [project-owned-agent documentation](https://github.com/PANIC-ANGEL-SCIENCE/exitbind/blob/main/docs/user-owned-agents.md) describes opt-in project profiles and lenses using existing capability preview/select routes, with project/role/expiry scope. It distinguishes ControlRoot profile paths from SourceRoot skill/lens paths and does not silently refresh running work.

If a future maintainer elects this route, follow the installed version's current documentation and choose the smallest relevant entry/reference set within its capability budget. Preserve existing profiles, root confinement, role mapping and active-work configuration. Do not paste this entire pack into every worker context. No capability descriptor, policy or Exitbind configuration is installed by this archive.

## Compatibility claims

Verified here: self-contained file structure, local documentation references, JSON metadata consistency, source coverage, package content controls and archive construction with included scripts.

Not verified: Claude/Codex installation or automatic triggering, native host execution, Exitbind marketplace inclusion, runtime capability selection, actual rendered design quality or improvements in success rate/cost. Those require their own real-environment acceptance before release claims.
